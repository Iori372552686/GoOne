# 技能设计的说服原则

## 概述

大型语言模型对与人类相同的说服原则做出响应。理解这种心理学有助于您设计更有效的技能 - 不是为了操纵，而是为了确保关键实践即使在压力下也能得到遵循。

**研究基础：** Meincke等人（2025年）用N=28,000次AI对话测试了7项说服原则。说服技巧使合规率提高了一倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**定义：** 对专业知识、证书或官方来源的尊重。

**在技能中的应用：**
- 命令语言："你必须"、"永不"、"始终"
- 非协商框架："没有例外"
- 消除决策疲劳和合理化

**适用场景：**
- 纪律强制执行技能（TDD、验证要求）
- 安全关键实践
- 已建立的最佳实践

**示例：**
```markdown
✅ 测试前写代码？删除它。重新开始。没有例外。
❌ 考虑在可行时先编写测试。
```

### 2. 承诺
**定义：** 与先前行为、声明或公开宣言保持一致。

**在技能中的应用：**
- 要求声明："宣布技能使用"
- 强制明确选择："选择A、B或C"
- 使用跟踪：用于检查清单的TodoWrite

**适用场景：**
- 确保技能被实际遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 找到技能时，您必须宣布："我正在使用[技能名称]"
❌ 考虑让您的伙伴知道您正在使用哪个技能。
```

### 3. 稀缺性
**定义：** 来自时间限制或有限可用性的紧迫感。

**在技能中的应用：**
- 时间绑定要求："在继续之前"
- 顺序依赖："在X之后立即"
- 防止拖延

**适用场景：**
- 即时验证要求
- 时间敏感工作流
- 防止"我稍后再做"

**示例：**
```markdown
✅ 完成任务后，立即请求代码审查，然后再继续。
❌ 您可以在方便时审查代码。
```

### 4. 社会证明
**定义：** 符合他人的行为或被认为是正常的事情。

**在技能中的应用：**
- 普遍模式："每次"、"始终"
- 失败模式："没有Y的X = 失败"
- 建立规范

**适用场景：**
- 记录普遍实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 没有TodoWrite跟踪的检查清单 = 步骤被跳过。每次都是。
❌ 有些人发现TodoWrite对检查清单有帮助。
```

### 5. 团结
**定义：** 共享身份、"我们"感、群体归属感。

**在技能中的应用：**
- 协作语言："我们的代码库"、"我们是同事"
- 共同目标："我们都想要质量"

**适用场景：**
- 协作工作流
- 建立团队文化
- 非等级实践

**示例：**
```markdown
✅ 我们是一起工作的同事。我需要您诚实的技术判断。
❌ 如果我错了，您可能应该告诉我。
```

### 6. 互惠
**定义：** 返回所获利益的义务。

**应用方式：**
- 谨慎使用 - 可能感觉被操纵
- 技能中很少需要

**避免场景：**
- 几乎总是（其他原则更有效）

### 7. 喜爱
**定义：** 偏好与我们喜欢的人合作。

**应用方式：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 产生谄媚

**避免场景：**
- 纪律强制执行时始终避免

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|----------|-----|-------|
| 纪律强制执行 | 权威 + 承诺 + 社会证明 | 喜爱、互惠 |
| 指导/技术 | 适度权威 + 团结 | 沉重权威 |
| 协作 | 团结 + 承诺 | 权威、喜爱 |
| 参考 | 仅清晰度 | 所有说服 |

## 为什么有效：心理学

**明确规则减少合理化：**
- "你必须"消除决策疲劳
- 绝对语言消除"这是例外吗？"的问题
- 明确的反合理化计数器关闭特定漏洞

**实施意图创造自动行为：**
- 清晰触发器 + 必需动作 = 自动执行
- "当X发生时，做Y"比"一般做Y"更有效
- 减少合规的认知负担

**大型语言模型是类人：**
- 接受包含这些模式的人类文本训练
- 训练数据中权威语言先于合规
- 频繁建模承诺序列（声明 → 动作）
- 社会证明模式（每个人都做X）建立规范

## 道德使用

**合法：**
- 确保关键实践得到遵循
- 创建有效文档
- 防止可预测的失败

**不合法：**
- 为个人利益操纵
- 创建虚假紧迫感
- 基于内疚的合规

**测试：** 如果用户完全理解这种技术，它会服务于用户的真正利益吗？

## 研究引用

**Cialdini, R. B. (2021).** *影响力：说服心理学（新版和扩展版）。* Harper Business.
- 七项说服原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** 叫我混蛋：说服AI遵守令人反感的请求。宾夕法尼亚大学。

- 验证LLM行为的类人模型

## 快速参考

设计技能时，问：

1. **它是什么类型？**（纪律 vs. 指导 vs. 参考）
2. **我试图改变什么行为？**
3. **哪些原则适用？**（纪律通常是权威 + 承诺）
4. **我组合了太多吗？**（不要使用全部七个）
5. **这符合道德吗？**（服务于用户的真正利益？）
