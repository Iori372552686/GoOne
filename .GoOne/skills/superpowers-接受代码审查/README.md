# 接受代码审查技能

## 概述

此技能用于处理代码审查反馈，以专业、尊重的态度处理审查评论，确保高质量的代码交付。

## 技能名称

**superpowers-接受代码审查**

## 核心功能

- 分类和理解审查评论
- 系统地处理每条评论
- 实施必要的修改
- 验证修改并回复评论

- 收到代码审查反馈需要处理时
- 需要系统地处理审查评论时
- 需要保持良好的审查礼仪时
