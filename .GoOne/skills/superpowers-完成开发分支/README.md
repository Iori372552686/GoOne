# 完成开发分支技能

## 概述

此技能用于完成功能开发后，确保代码质量、运行最终验证、清理分支并安全合并到主分支。

## 技能名称

**superpowers-完成开发分支**

## 核心功能

- 运行完整测试套件
- 执行代码审查
- 清理调试代码和临时文件
- 更新文档
- 安全合并到主分支

## 文件结构

```
superpowers-完成开发分支/
└── SKILL.md                 # 主技能文档
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 核心技能文档，包含分支完成流程和检查清单 |

## 使用场景

- 完成功能开发准备合并
- 执行最终验证和代码审查
- 清理分支并合并到主分支
