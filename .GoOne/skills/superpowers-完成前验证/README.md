# 完成前验证技能

## 概述

此技能用于在声称工作完成之前运行验证命令并确认输出，确保先有证据后有断言。

## 技能名称

**superpowers-完成前验证**

## 核心功能

- 运行测试验证
- 检查代码质量
- 确认构建成功
- 验证需求满足

## 文件结构

```
superpowers-完成前验证/
└── SKILL.md                 # 主技能文档
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 核心技能文档，包含验证流程和检查清单 |

## 使用场景

- 即将声称工作完成时
- 在提交或创建PR之前
- 需要确认测试通过时
- 需要验证修复效果时
