# 测试驱动开发技能

## 概述

此技能用于在编写实现代码之前实施任何功能或bug修复，遵循RED-GREEN-REFACTOR循环。

## 技能名称

**superpowers-测试驱动开发**

## 核心功能

- 编写失败测试（RED）
- 实施最小代码使测试通过（GREEN）
- 重构代码（REFACTOR）
- 防止测试反模式

## 文件结构

```
superpowers-测试驱动开发/
├── SKILL.md                 # 主技能文档
└── testing-anti-patterns.md # 测试反模式指南
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 核心技能文档，包含TDD流程和规则 |
| `testing-anti-patterns.md` | 测试反模式指南，避免常见错误 |

## 使用场景

- 实现新功能时
- 修复bug时
- 需要确保代码质量时
- 需要可测试的代码设计时
