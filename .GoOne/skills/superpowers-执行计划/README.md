# 执行计划技能

## 概述

此技能用于在当前会话中执行预先编写的实施计划。按顺序执行任务，在关键检查点进行审查，确保每个阶段都正确完成。

## 技能名称

**superpowers-执行计划**

## 核心功能

- 加载和解析实施计划
- 按顺序执行计划任务
- 在检查点进行审查验证
- 跟踪任务完成状态

## 使用场景

- 执行多步骤实施计划
- 批量处理任务并进行阶段性审查
- 在单个会话中完成多个相关任务
