# 并行代理调度技能

## 概述

此技能用于并行执行多个独立任务以加速工作流程。当多个任务可以独立完成时，同时调度多个子代理，然后综合结果。

## 技能名称

**superpowers-并行代理调度**

## 核心功能

- 识别可并行执行的独立任务
- 同时调度多个子代理工作
- 收集和综合并行任务的结果
- 处理任务超时和错误

- 分析多个相关文件

- 同时收集不同数据源的信息
