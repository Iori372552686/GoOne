# 使用Git工作树技能

## 概述

此技能用于创建隔离的git工作树，在执行实施计划之前提供独立的开发环境。

## 技能名称

**superpowers-使用Git工作树**

## 核心功能

- 创建隔离的git工作树
- 智能目录选择
- 安全验证
- 工作树管理

- 在执行实施计划之前创建独立环境时
- 需要并行处理多个分支时
