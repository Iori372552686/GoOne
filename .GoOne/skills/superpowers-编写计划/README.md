# 编写计划技能

## 概述

此技能用于为多步骤任务编写全面的实施计划，确保每个任务都有明确的步骤、测试和验证方法。

## 技能名称

**superpowers-编写计划**

## 核心功能

- 创建详细的实施计划
- 定义任务结构和步骤
- 编写测试用例
- 制定验证检查清单

## 文件结构

```
superpowers-编写计划/
├── SKILL.md                 # 主技能文档
└── plan-document-reviewer-prompt.md  # 计划文档审查者提示模板
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 核心技能文档，包含计划编写流程和模板 |
| `plan-document-reviewer-prompt.md` | 计划文档审查者子代理的提示模板 |

## 使用场景

- 有用于多步骤任务的规范或需求时
- 需要在接触代码之前规划实施时
- 需要创建清晰的任务分解时
