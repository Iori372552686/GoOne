# 请求代码审查技能

## 概述

此技能用于准备清晰的代码审查请求，帮助审查者高效地理解和评估工作成果。

## 技能名称

**superpowers-请求代码审查**

## 核心功能

- 准备完整的PR模板
- 编写清晰的变更说明
- 指定合适的审查者
- 确保测试通过和代码质量

## 文件结构

```
superpowers-请求代码审查/
├── SKILL.md                 # 主技能文档
└── code-reviewer.md         # 代码审查代理提示模板
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 核心技能文档，包含PR创建流程和提交规范 |
| `code-reviewer.md` | 代码审查代理的提示模板 |

## 使用场景

- 准备提交代码进行审查时
- 需要创建清晰的PR描述时
- 需要确保审查质量时
